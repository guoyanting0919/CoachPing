# 03: 恢復合作

**What to build:** 結束合作的反向動作。教練手滑、或學員三個月後回來時走這條。

同一支 `PATCH /api/coach/members/[id]`。只恢復關係，**不復活**當初取消的課：
取消那刻已經推播告知學員課沒了，復活等於再推一次「其實還有」，
而那些時段可能早就被別人約走。

**Blocked by:** 02

**Status:** ready-for-human（實作完成，待 db:push 與真機驗收）

- [ ] 關係轉回 `active`，`ended_at` 清回 `null`
- [x] 當初取消的課維持 `cancelled`，不復活
- [ ] 恢復後教練立刻能為他排課、學員立刻能向他預約
- [x] 未連結學員恢復時自動產生一張新邀請（結束時舊的已作廢），清單上直接能複製連結
- [x] 已連結學員不產生邀請
- [x] 不推播任何訊息給學員
- [x] 對已經是 `active` 的關係重複呼叫是安全的

## 實作紀錄

與 02 同一支 `PATCH`。`status` 轉回 `active`、`endedAt` 清 `null`，課一律不動。

未連結學員恢復時直接建一張新邀請並回傳 `inviteUrl`——02 結束時把他手上那張作廢了，
不補一張他就永遠進不來。已連結的不產生（回 `null`）。

已經是 `active` 就直接回 `ok` 且不產生邀請，避免重複送出多出一堆有效連結。
